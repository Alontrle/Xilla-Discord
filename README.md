# Xilla-Discord
A simple but powerful discord Java library built using the Xilla Boot software and JDA to streamline discord bot development.

The main goal of this project is to simplify and streamline java discord bot development. This library handles all major bot development functions. it has built in data management with Xilla Boot and uses the internal scanning system to make bot development super quick and easy.
